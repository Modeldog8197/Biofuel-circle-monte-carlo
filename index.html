Driver Analysis

Which operational metrics most influence our business results?

🔍
What is this? We tested every metric in the dataset to see which ones are most connected to our sell trades and manual responses. Think of it like figuring out which ingredients matter most in a recipe.
  • Pearson r = how closely two metrics move together (1.0 = perfectly together, 0 = no connection)
  • Composite Score = a combined importance ranking from 3 different machine learning models
  • R² = how much of the outcome our model can explain (0.98 = 98% explained, which is very high)

Leading Indicators (Lag Analysis)

Can this month's metrics predict next month's results?

⏱️
What is this? This is perhaps the most useful section for daily decision-making. We tested whether knowing this month's numbers can predict next month's performance. The answer is yes — with 97%+ accuracy.
  • Lag 0 = same month (concurrent relationship)
  • Lag 1 = this month's driver → next month's outcome (1-month lead)
  • Lag 2/3 = 2–3 month advance signals
A high Lag-1 correlation means that metric is a leading indicator — an early warning system for management.
✅ Key Finding: This month's operational data predicts next month's outcomes with R² = 0.96–0.98. Management has a reliable 1-month forward visibility window.

What-If Scenario Analysis

If we change one lever, how much does it move the needle?

🧪
What is this? We built a prediction model, then asked: "What happens if we increase Platform Delivery Volume by 10%? Or Open Interest by 20%?" These are simulated experiments — we change one input while keeping everything else the same, and measure the predicted impact.
  • Baseline = the model's prediction using Apr 2026 values as inputs
  • Δ% = how much the prediction changes when we adjust one lever
  • Larger Δ% = that lever has more power to move outcomes

Executive Summary

Key findings, risks, opportunities, and action items

📋
For senior management: This section condenses the entire analysis into actionable insights. It highlights what's going well, what to watch out for, and specific recommendations prioritised by timeframe.

🎯 Key Findings

  • Massive Growth: Sell trade count up 560%, manual responses up 3,043% since Oct 2022
  • #1 Driver: Total Trades count & Trades ARR are the strongest correlated metrics (r=0.97)
  • Predictability: Next month's results can be predicted from this month's data (R² up to 0.98)
  • Platform Delivery: The most actionable lever — +20% delivery drives +10.5% sell trade volume

⚠️ Risks

  • High Volatility: Sell trade volumes swing wildly month-to-month (e.g. 88K to 746K)
  • Manual Response Surge: 3,043% growth signals operational scaling challenges
  • Data Gaps: Deal Volume Supply Chain has 52% missing data — limits analysis reliability
  • Outliers: Trades Lost and Market share contain negative values and extreme spikes

🚀 Opportunities

  • Platform Delivery +20%: Single most impactful lever — +10.5% sell trade volume, +6% manual response count
  • Unique Participants: Strongest lagged predictor — growing the participant base drives future trades
  • Predictive Dashboard: The lag models (R²=0.97) can power a real-time early-warning system
  • Automation: Manual responses growing faster than trades — automate to prevent bottleneck

✅ Recommendations

Immediate (30 days)

  • Set up weekly monitoring for Unique Participants & Platform Delivered Vol
  • Investigate and fix data gaps in Deal Volume Supply Chain
  • Review extreme Trades Lost values for data quality

Short-Term (Quarter)

  • Invest in Platform Delivery capacity (+20% target)
  • Begin automating manual response workflows
  • Expand unique participant acquisition programs

Strategic (12 Months)

  • Build real-time predictive monitoring using lag models
  • Scale rural warehouse network (emerging predictor)
  • Re-run this analysis quarterly with updated data
